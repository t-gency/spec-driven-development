# Investigation

Pre-spec research, audits, post-mortems, market analysis. Everything that informs a decision but
is not itself a decision or a specification.

**Dated, and never retro-edited.** A snapshot that gets updated stops being evidence of what was
known at the time, which is the only reason to keep it.

## Naming

`YYYY-MM-DD-what-was-investigated.md`. The date is part of the filename because the date is part
of the meaning.

## Rules

- **Separate verified from inferred.** Mark what you could not confirm as `[UNVERIFIED — reason]`
- **Cite the evidence** so someone can re-run it
- **Say what it does not tell you.** The limits are usually the most useful part later
- **When it produces a decision, that decision becomes an ADR.** This file stays as its evidence
- **Wrong later?** Write a new one and link back. Do not edit this one

Start from `TEMPLATE.md`.
